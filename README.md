# 🎮 dem.Toshka

**dem.Toshka** — современное настольное приложение для анализа демок Counter-Strike 2 (`.dem`), автоматического обнаружения лучших моментов матча (ACE, клатчи, мультикиллы, энтри-фраги) и высококачественной записи видеоклипов в 60 FPS через HLAE и CS2.

---

## ✨ Ключевые возможности

### 🎬 Двухфазный Турнирный Килл-кам (Instant Replay Kill-cam)
Кинематографический режим трансляций BLAST Premier и ESL Pro League:
1. **Фаза жертвы:** камера фиксирует ситуацию от лица погибающего игрока, показывая удержание позиции и эпический момент смерти на экране с падением ragdoll.
2. **Мгновенный реплей назад:** демка автоматически перематывается на 4 секунды назад, камера переключается на Главного Героя (ГГ), демонстрируя наводку, выстрел и доигрывание момента от первого лица победителя.
3. **Бесшовный монтаж:** обе фазы автоматически объединяются в единый MP4 через FFmpeg.

### 📐 Киберспортивный формат 4:3 (1280×960 Stretched & 1440×1080)
- Поддержка турнирного разрешения **1280×960 (4:3 растянутый)** и **1440×1080** для широких моделек противников и крупных хитбоксов.
- Настройка FOV камеры (68°–105°) и турнирного Viewmodel (60°–68°).
- Интерактивный предпросмотр кастомных прицелов (Pro Cyan, Clean Green, Movie Dot, Thin White) на фонах реальных карт CS2.

### 🎯 Huge HUD (115% / 125%) & Dynamic Radar (130%)
- **Huge HUD:** увеличенные индикаторы здоровья `+ 100`, брони и боезапаса, четко различимые при просмотре с любых устройств.
- **Dynamic Radar 130%:** увеличенный радар, вращающийся вместе со взглядом игрока.
- **Broadcast Giant Overview:** фиксированный турнирный радар с обзором всей карты и позиций тиммейтов.
- **Интерактивный симулятор:** наглядная витрина со скриншотами и консольными командами для карт *Mirage, Inferno, Nuke, Dust II, Anubis*.

### 📊 FACEIT-подобная аналитика и аудит ошибок
- Расчет киберспортивных показателей: **K/D**, **ADR**, **Headshot %**, **Opening Duel Winrate**, **KAST %**, **Clutch Winrate**.
- **SWING-индекс:** оценка перелома раунда при игре в меньшинстве (3v5, 2v4).
- **Автоматический аудит тактических ошибок:** выявление невынужденных первых смертей на защите CT, пушей при численном преимуществе 5v3 / 4v2 и смертей вслепую.
- Режим «⭐ Это мой профиль»: сохранение выбранного игрока без необходимости регистрации.

### ⚡ Пакетная запись (Continuous Single-Launch Batching)
- Очередь рендеринга объединяет клипы одного матча и записывает их за **один непрерывный запуск CS2**, экономя минуты ожидания загрузки карт.
- Быстрая перемотка демки (`demo_gototick`) исключает холостой просмотр тиков между хайлайтами.

### 🖥️ Профессиональный плеер без перекрытия интерфейса
- Панель управления плеера вынесена в выделенный нижний док строго под видео, благодаря чему нижняя полоса CS2 с HP и патронами никогда не перекрывается.

## 🚀 Быстрый старт (Windows)

### Запуск в один клик:
- **`start_app.bat`** — проверяет Python `.venv` и `Node.js`, освобождает порты 8000 и 5173, запускает бэкенд и фронтенд и открывает браузер по адресу `http://localhost:5173`.
- **`stop_app.bat`** — корректно останавливает все фоновые сервисы приложения.

---

### Ручной запуск (для разработки):

#### 1. Бэкенд (FastAPI + Python 3.10+)
```powershell
# Активация виртуального окружения
.venv\Scripts\activate

# Запуск API сервера
uvicorn backend.api.main:app --host 127.0.0.1 --port 8000 --reload
```
Документация Swagger UI доступна по адресу: `http://127.0.0.1:8000/docs`

#### 2. Фронтенд (React + TypeScript + Vite)
```powershell
cd frontend
npm install
npm run dev
```
Интерфейс доступен по адресу: `http://localhost:5173`

## 🔒 Безопасность и целостность данных

- **Локальная работа:** все данные хранятся локально на компьютере пользователя, вход в аккаунты Steam/FACEIT не требуется.
- **Неприкосновенность файлов:** исходные `.dem` файлы никогда не перезаписываются и не удаляются.
- **Изоляция CS2:** игра запускается с безопасными турнирными параметрами `-steam -insecure +sv_lan 1 -afxDisableSteamStorage`.
- **Защита от Path Traversal:** строгая валидация всех путей к файлам демок и директориям вывода.
