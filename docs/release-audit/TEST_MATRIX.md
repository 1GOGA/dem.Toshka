## 3. Непроверенные области (NOT ASSESSED)

1. **Многочасовой непрерывный рендер 20+ клипов подряд:** Физический стресс-тест видеокарты и диска на 120 FPS требует 40+ минут реального времени с запущенной CS2.
2. **Экзотические разрешения мониторов (32:9 Super Ultrawide, 49 дюймов):** Проверялись разрешения 1920×1080 (Full HD) и 2560×1440 (2K).
3. **Работа на Windows 10 без установленных обновлений Media Feature Pack:** Предполагается наличие нативных кодеков H.264/AAC в ОС.
